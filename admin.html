Informasi Sekolah

Antrean Login Massal

Atur sesuai paket Supabase. Mode Free lebih aman untuk login massal (~1500 pemilih). Mode Pro lebih cepat jika server sudah di-upgrade.

Rekomendasi: 80 untuk Free tier, 200 untuk Pro. Pemilih lain menunggu otomatis jika slot penuh.

Ditampilkan sebagai hitung mundur di footer bilik suara. Jika habis, pemilih otomatis keluar dan harus login ulang dari awal.

Batas maksimal pemilih menunggu ketika kapasitas bilik sedang penuh sebelum diminta mencoba login lagi.

Zona Bahaya (Danger Zone)

Tindakan berikut bersifat permanen dan tidak dapat dibatalkan. Pastikan Anda telah mengunduh data penting sebelum melanjutkan.

Hapus Semua Hasil Voting

Tindakan ini akan mereset status voting semua pemilih (siswa, guru, staf) menjadi "Belum Memilih" dan mengembalikan perolehan suara semua kandidat ke 0.

Hapus Semua Data (Kosongkan)

Tindakan ini akan menghapus seluruh data pemilih (siswa, guru, staf), data kandidat, serta log voting dari Supabase. Akun admin, sesi admin, dan pengaturan aplikasi tetap aman, serta file gambar di Supabase Storage tidak ikut terhapus.
